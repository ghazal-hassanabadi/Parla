# پارلا | فروشگاه اینترنتی جواهرات

پارلا یک فروشگاه اینترنتی ساده برای زیورآلات و جواهرات است. این پروژه نسخهٔ اصلاح‌شدهٔ کامل پارلای قبلی من است. طراحی ظاهر از ابتدا با تیلویند دوباره ساخته شد، ساختار صفحه‌ها معنایی‌تر شد و کدهای جاوااسکریپت به بخش‌های کوچک و جدا تقسیم شدند.

## لینک خروجی

[https://ghazal-hassanabadi.github.io/Parla/]

## صفحه‌های پروژه

- صفحهٔ اصلی با اسلایدر پیشنهادهای ویژه، دسته‌بندی‌های محبوب و پرفروش‌ترین محصولات
- صفحهٔ فروشگاه با فهرست محصولات و پنل فیلتر
- صفحهٔ جزئیات محصول با گالری تصاویر، انتخاب تعداد و تب‌های توضیحات، مشخصات و نظرات
- صفحهٔ تماس با ما
- صفحهٔ ثبت نام

همهٔ صفحه‌ها برای موبایل، تبلت و دسکتاپ طراحی شده‌اند و جهت نوشتار آن‌ها راست‌به‌چپ است.

## کامپوننت‌های پایه

سه کامپوننت اصلی پروژه جدا از هم و از روی طرح ساخته شدند. زمان ساخت هرکدام زیر سی دقیقه بود:

- کارت محصول
- نوار ناوبری
- فرم ورود

## فناوری‌ها

- اچ‌تی‌ام‌ال معنایی، با استفاده از المان‌هایی مثل سربرگ، ناوبری، بخش، مقاله، شکل و فهرست
- تیلویند نسخهٔ ۴ با ابزار خط فرمان و رنگ‌ها و فونت‌های اختصاصی برند
- جاوااسکریپت ماژولی، شامل اسلایدر خودکار، گالری تصاویر، انتخاب تعداد و تب‌ها
- فونت وزیرمتن برای متن فارسی و فونت کورمورانت گارامون برای نام برند
- آیکن‌ها از کتابخانهٔ فونت‌آوسام

## نکته‌هایی دربارهٔ ساخت پروژه

- بخش اصلی طراحی، چیدمان و کدنویسی را خودم انجام دادم.
- برای یک سری کلاس‌های جدید تیلویند از هوش مصنوعی به‌عنوان راهنما کمک گرفتم.
- عکس‌ها و محتوای نوشتاری سایت (مثل توضیحات محصولات و نظرها) را از هوش مصنوعی گرفتم.
- در تحلیل بعضی قسمت‌های جاوااسکریپت هم هوش مصنوعی به من کمک کرد.

## نحوهٔ اجرا

۱. پروژه را دانلود یا کلون کنید.

۲. وابستگی‌ها را نصب کنید:

```bash
npm install
```

۳. برای ساخت فایل استایل، دستور زیر را اجرا کنید و آن را باز بگذارید:

```bash
npx @tailwindcss/cli -i ./src/input.css -o ./src/output.css --watch
```

۴. چون جاوااسکریپت به‌صورت ماژول نوشته شده، صفحه را باید با یک سرور محلی (مثل افزونهٔ لایو سرور) باز کنید. باز کردن مستقیم فایل با دوبار کلیک کار نمی‌کند.
